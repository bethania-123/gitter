Here’s a clear guide on **how to turn text into speech with code**, covering the most practical options.

### 1. Easiest – Browser (JavaScript) – Web Speech API
Works in Chrome, Edge, Safari, Firefox with no extra libraries.

```html
<!DOCTYPE html>
<html>
<body>
  <textarea id="text" rows="4" cols="50">Hello, this is text to speech!</textarea><br>
  <button onclick="speak()">Speak</button>

  <script>
    function speak() {
      const text = document.getElementById('text').value;
      const utterance = new SpeechSynthesisUtterance(text);
      
      // Optional settings
      utterance.lang = 'en-US';       // language
      utterance.rate = 1;             // speed (0.1 – 10)
      utterance.pitch = 1;            // pitch (0 – 2)
      utterance.volume = 1;           // volume (0 – 1)
      
      // Choose a voice (optional)
      const voices = speechSynthesis.getVoices();
      utterance.voice = voices.find(v => v.name.includes('Google') || v.lang === 'en-US');
      
      speechSynthesis.speak(utterance);
    }
    
    // Load voices (they load asynchronously)
    speechSynthesis.onvoiceschanged = () => console.log(speechSynthesis.getVoices());
  </script>
</body>
</html>
```

### 2. Python – Offline (no internet needed)
Uses `pyttsx3` (works on Windows, macOS, Linux).

```bash
pip install pyttsx3
```

```python
import pyttsx3

engine = pyttsx3.init()

# Optional settings
engine.setProperty('rate', 150)      # speed
engine.setProperty('volume', 0.9)    # volume (0–1)

# List available voices
voices = engine.getProperty('voices')
for voice in voices:
    print(voice.id, voice.name)

# Choose a voice (example)
# engine.setProperty('voice', voices[1].id)

text = "Hello, this is offline text to speech in Python."
engine.say(text)
engine.runAndWait()
```

### 1. Best Free Online Option (Recommended) – `edge-tts`
Microsoft Edge neural voices. High quality, no API key, excellent female Swahili voices.

**Install:**
```bash
pip install edge-tts
```

**Female Swahili + English example:**

```python
import asyncio
import edge_tts

async def text_to_speech(text, voice, output_file="output.mp3"):
    communicate = edge_tts.Communicate(text, voice)
    await communicate.save(output_file)
    print(f"Saved: {output_file}")

# Best female voices
SWAHILI_FEMALE = "sw-KE-ZuriNeural"      # Kenya - friendly female
SWAHILI_FEMALE_TZ = "sw-TZ-RehemaNeural" # Tanzania - female
ENGLISH_FEMALE = "en-US-AriaNeural"      # Natural US female
# Other good English females: en-US-JennyNeural, en-GB-SoniaNeural, en-US-MichelleNeural

async def main():
    # English
    await text_to_speech(
        "Hello, my name is Zuri. How are you today?",
        ENGLISH_FEMALE,
        "english_female.mp3"
    )

    # Swahili
    await text_to_speech(
        "Habari yako? Jina langu ni Zuri. Ninafurahi kukutana nawe.",
        SWAHILI_FEMALE,
        "swahili_female.mp3"
    )

asyncio.run(main())
```

### 2. Simple Free Online – `gTTS` (Google)
Very easy, but less natural and limited voice control.

```bash
pip install gTTS playsound
```

```python
from gtts import gTTS
from playsound import playsound
import os

def speak(text, lang="en", filename="speech.mp3"):
    tts = gTTS(text=text, lang=lang, slow=False)
    tts.save(filename)
    playsound(filename)
    # os.remove(filename)  # optional

# English
speak("Hello, this is a female Google voice.", lang="en")

# Swahili
speak("Habari yako? Ninafurahi kukuona.", lang="sw")
```

> Note: gTTS does not let you force male/female reliably.

### 3. Offline (Free) – `pyttsx3` + eSpeak
Works without internet. Quality is robotic, but usable.

**Install (Linux):**
```bash
pip install pyttsx3
sudo apt update && sudo apt install espeak espeak-data libespeak1 ffmpeg
```

```python
import pyttsx3

engine = pyttsx3.init()

# List available voices
voices = engine.getProperty('voices')
for i, voice in enumerate(voices):
    print(f"{i}: {voice.id} | {voice.name} | {voice.languages}")

# Try to set a female-sounding voice (depends on your system)
# On many Linux systems with espeak:
engine.setProperty('voice', 'sw')          # Swahili
# or engine.setProperty('voice', 'en+f3')  # English female variant (if available)

engine.setProperty('rate', 150)   # speed
engine.setProperty('volume', 0.9)

# English
engine.say("Hello, this is offline speech.")
engine.runAndWait()

# Swahili
engine.say("Habari, hii ni sauti ya offline.")
engine.runAndWait()
```

**Better offline quality** (more advanced): Use **Piper TTS** or Hugging Face models (F5-TTS Swahili, VITS Swahili). These give much more natural offline voices but need model download.

#### B. ElevenLabs (best quality + many female voices + Swahili)

```bash

```

```python
from elevenlabs.client import ElevenLabs
from elevenlabs import play, save

client = ElevenLabs(api_key="YOUR_API_KEY")

audio = client.text_to_speech.convert(
    text="Habari yako? Hello, this is a beautiful female voice in Swahili and English.",
    voice_id="EXAVITQu4vr4xnSDxMaL",  # example female voice (Rachel etc.)
    model_id="eleven_multilingual_v2",  # or eleven_v3
    output_format="mp3_44100_128"
)

save(audio, "elevenlabs_female.mp3")
# play(audio)
```

ElevenLabs v3 supports Swahili (`SWA`).
